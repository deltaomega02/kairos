## 1. 워뇨띠 (한국 코인 트레이더 No.1) — 핵심 학습

### 정체
- 디시 차트갤러리 고정닉 / 키 182cm / 닉네임: 아이브 장원영 별명 '워뇨'에서
- 2017년 600만원 → 2024년 약 ₩4,080억 (비트멕스 리더보드 검증)
- 2025-04: 이더리움 640억 매수 → 하루 +85억

### 매매 원칙 (100문 100답)

| 항목 | 워뇨띠 | KAIROS 적용 |
|---|---|---|
| 분석 비중 | **차트 90% + 호재 10%** | 지표 최소화 (워뇨띠 본질) |
| 보조지표 | **안 씀** | RSI/BB 제거 검토 |
| 핵심 | 시장 참여자 심리 읽기 | 자동매매로는 한계 → 단순 룰로 대체 |
| 시드 추가 | **절대 X** | KAIROS 룰로 채택 |
| 손절 | 시나리오 어긋나면 즉시 | 자동 SL로 대체 |
| 분할 | 거래량 부족 + 변동성 클 때 | 1회 진입 단순화 (소액 시드) |
| 코인 비중 | 비트 70 / 이더 20 / 알트 10 | **BTC 단일 채택** (단순화) |

### 결론
워뇨띠 자체 모사는 불가능 (수년 학습 + 수동). 그러나 **"단순화 + 시드 보호"는 자동매매에도 유효**.

## 4. 한국 자동매매 봇 통계

### 1순위 검증 전략: **변동성 돌파 (래리 윌리엄스)**
```python
target_price = today_open + (yesterday_high - yesterday_low) * K
# K = 0.6 ± 0.2 (3년 백테스트 0.6 최고)
# 매수: target_price 돌파 시
# 매도: 다음날 시가 (또는 종가)
```
- 한국 자동매매 가장 인기 전략
- 코스닥 + 암호화폐 같은 개인 비중 큰 시장에 효과적
- 헤이비트(상용 서비스)도 이 전략 기반

### pyupbit 생태계
- `youtube-jocoding/pyupbit-autotrade` (조코딩 강의)
- `hyeon9698/upbit_bot` (변동성 돌파 + 텔레그램)

### 한국 자동매매 1년 흑자 통계

```
한국 가상자산 투자자: 2,163만명
├── 100만원 미만: 826만명 (74.2%)  ← 운영자 위치
├── 100만~1000만: ~22%
└── 1억원+: 17만명 (1.5%)

원화예치금: -43%
거래소 영업이익: -17%
가상자산 변동성: 70%
```

### ₩100만 1년 후 분포 추정 (정직)
| 시나리오 | 확률 | 결과 |
|---|---|---|
| 큰 손실 (-50%+) | 30% | ₩50만 이하 |
| 손실 (-10~-50%) | 30% | ₩50~90만 |
| 보존 (±10%) | 20% | ₩90~110만 |
| 수익 (+10~50%) | 15% | ₩110~150만 |
| 큰 수익 (+50%+) | 5% | ₩150만+ |

→ **기대값 마이너스. 60% 확률로 손실.**

### 성공 그룹의 룰
1. 시드 분할
2. 분할 매수/매도
3. 손절 기준 명확
4. 수익 일부 출금 (재투자 안 함)
5. 일일 손실 한도

## 6. HERMES v1 17일 운영 분석 (KAIROS 탄생 배경)

### 숫자 (CSV 분석)
```
기간: 2026-04-09 ~ 2026-04-26 (17일)
거래: 38건
누적 손익: -$49.62 / -₩72,931 (시드 대비 -9%)

승률: 16/38 = 42.1%   ← 백테스트 57.2%보다 -15%p
평균 승: $7.48
평균 패: $7.70
실제 R:R: 0.97        ← 백테스트 0.88과 유사
기대값/거래: -1.3%   ← 마이너스
```

### 진단
- **R:R은 작동**. 트레일링 시스템 OK.
- **승률 -15%p**. 마켓 환경 + 슬리피지 + 약신호 진입 등이 원인.
- 17일/38거래 = 통계적 결론 못 냄.
- **그러나 v# 변경 5회/17일 = 과적합 안티패턴 발동 중** ← KAIROS 분리 트리거

### 학습
1. 잦은 v# 변경 = 적신호 (50거래까지 동결)
2. 백테스트 절대값 신뢰 X (단일 경로)
3. 단순화 시도 정당화 (워뇨띠 + 한국 통계 일치)
4. 같은 거래소에서 다른 전략으로 분산이 합리적
