## 채택 전략: **BTC 일봉 변동성 돌파 (Larry Williams)**

### 한 줄
> 매일 시가 기준으로 어제 변동폭의 60%만큼 돌파하면 매수, 다음날 시가에 청산.

### 작동 원리

```python
# 매수 조건 (LONG)
range = yesterday_high - yesterday_low
target_price = today_open + range * K     # K = 0.6 (기본)
if current_price >= target_price:
    enter_long()

# 청산 조건
if current_time >= next_day_open_time:    # 다음날 시가
    exit_position()
```

### 변동성 돌파 변형 후보 (백테스트 후 선택)
1. **기본**: K=0.6, 다음날 시가 청산
2. **목표 익절**: 진입가 +R 도달 시 익절 (R = range × K)
3. **종가 청산**: 다음날 종가 청산
4. **변동성 필터**: range가 너무 작으면(<1%) 진입 안 함
5. **추세 필터**: 5일 또는 10일 이평 위에서만 진입

## HERMES와의 비교

| 항목 | HERMES v1 | KAIROS v2 |
|---|---|---|
| 거래소 | Bybit | Bybit (동일) |
| 코인 | BTC/ETH/SOL/XRP | **BTC만** |
| 전략 | 4H 추세풀백 + 다중 지표 | **일봉 변동성 돌파 + K=0.6** |
| 시간봉 | 1H + 4H + 1D | **1D만** |
| 지표 | EMA + RSI + BB + ADX + ATR + MACD + 오더북 + 펀딩 | **range + open만** |
| 레버리지 | 7x | **3x** |
| SL | 1.5×ATR | **고정 -2%** |
| TP | 6×SL | **없음 (다음날 시가)** |
| 트레일링 | 1.2%/0.1% | **없음** |
| 방향 | LONG + SHORT | **LONG만** |
| 진입 빈도 | 1H마다 체크 | 일 1회 |
| 체크 주기 | 60초 | 5분 |

→ 진정한 환경 분산. HERMES가 잘 안 되는 환경(횡보/약변동)에서 KAIROS가 작동할 수 있음.

## 백테스트 계획

### 데이터
HERMES `backtest/data/` 재활용. BTCUSDT 일봉 6년치 (2020~2026).

### 검증 항목
1. **K값 sweep**: 0.3 ~ 0.9 (0.05 단위) → 최적 K 찾기
2. **시드 시뮬**: $1000 시작 6년 곡선
3. **드로다운**: 최대 DD %
4. **거래 횟수**: 연 평균 (일 1회 X, 진입 조건 만족 시만)
5. **승률**: 단순 LONG only 변동성 돌파 승률
6. **R:R**: 평균 승/패
7. **HERMES와 같은 기간 비교**: 두 시스템 누적 차이

### 검증 기준 (실전 가동 결정)
- **6년 누적 +200% 이상** (DCA 5년 +202% 대비)
- **최대 DD < 50%** (HERMES와 비교)
- **승률 > 40%** (변동성 돌파 평균)
- **연 거래 30회 이상** (수수료 영향 미미)

## 위험 솔직 공개 (운영자 알아야 함)

1. **변동성 돌파는 추세장에 강하고 횡보장에 약함**
   - 2022년 같은 횡보장은 반복 손절 가능
2. **K값 백테스트 과최적화 위험** ← 안티패턴
   - K=0.6은 다른 사람들도 검증한 값이라 그나마 안전
3. **일봉 1회 진입 = 슬리피지 영향 큼**
   - 시가 청산 = 갭 손실 가능
4. **LONG only = 하락장에 자금 놀음**
   - HERMES도 같은 약점, KAIROS는 더 심함
5. **연 30~50회 거래 = 통계적 검증 시간 오래 걸림**
   - 1년 운영해도 50거래 정도
